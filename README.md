# CLI Flashcard System App

A command-line tool that displays a basic flashcard card by a flipping fashion, showing the answer when Enter is clicked.

What it does:
- Displays 5 sets of flashcards
- Allows user to input feedback on how difficult the question is (function is currently limited)

Future updates:
- Implement add, modify, remove actions for cards
- Store cards in a .txt file
- Create a spaced repetition system for retrieval
- Integrate AI for personal feedback
